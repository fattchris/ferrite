⚜ FERRITE ⚜

by Kassett
"Persistent memory for autonomous AI agents"

A temporal knowledge graph that gives AI agents long-term memory. Agents forget nothing — every conversation, document, and research paper becomes queryable knowledge.


▶ Deploy in 5 Minutes   View Features »
★ Features ★ (Double-click any icon to learn more!)
G Temporal Knowledge Graph
» Neo4j-powered graph database
Stores entities, relationships, and facts with full temporal versioning. Time-travel through your agent's knowledge — see what was known at any point in history.
O Observation Consolidation
» Facts → Evidence-backed beliefs
Raw facts don't just pile up. Ferrite consolidates them into weighted observations with full evidence trails. Your agent knows not just what it knows, but why and how confident it is.
T TEMPR Multi-Strategy Retrieval
» 4 search strategies, fused
Semantic search + BM25 keyword + graph traversal + temporal reasoning, combined via Reciprocal Rank Fusion (RRF). The right answer, no matter how your agent phrases the query.
N Multi-Agent Namespace Isolation
» Separate agents, shared infra
Run multiple agents on one Ferrite instance with full namespace isolation. Each agent sees only its own knowledge graph — no cross-contamination, no data leakage.
L Self-Hosted LLM Extraction
» Zero API cost, full privacy
Entity and fact extraction runs on DS-V4-Flash, self-hosted on your own infrastructure. No per-token API fees, no data leaving your network. Your knowledge stays yours.
F File Storage
» PDFs, code, web archives
Store and retrieve raw files alongside structured knowledge. Agents can reference the source document behind any extracted fact — full provenance, always traceable.
V Pluggable Vector Store
» Bring your own embeddings backend
Ferrite ships with nomic-embed-text-v1.5 out of the box, but the vector store is fully pluggable. Swap in your preferred backend without touching agent logic. Defaults that work, flexibility when you need it.
▸ How It Works ▸
1
Store
Agents store conversations and documents via MCP (Model Context Protocol). Anything an agent reads, writes, or discusses flows into Ferrite automatically.
▼
2
Extract
A self-hosted LLM (DS-V4-Flash) extracts entities and facts from raw content. Zero API cost, full privacy — extraction runs on your own infrastructure.
▼
3
Consolidate
Facts consolidate into evidence-backed observations. Conflicting evidence is reconciled with confidence scores and temporal versioning — your agent develops a coherent worldview.
▼
4
Retrieve
TEMPR retrieval fuses 4 search strategies — semantic, BM25, graph traversal, and temporal reasoning — via Reciprocal Rank Fusion (RRF). Your agent gets the right answer, every time.
