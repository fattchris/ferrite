FERRITE

Persistent Memory for AI Agents

A temporal knowledge graph that gives AI agents long-term memory. Agents forget nothing — every conversation, document, and research paper becomes queryable knowledge.

Deploy in 5 Minutes

FEATURES

TEMPORAL GRAPH

Every fact timestamped with valid_at and invalid_at. Track knowledge changes over time. Neo4j deep graph traversal.

plays on repeat

CONSOLIDATION

Raw facts auto-consolidate into evidence-backed beliefs. Proof counts, evidence chains, staleness tracking from Hindsight.

gold

TEMPR SEARCH

Four parallel strategies: semantic, BM25, graph, temporal. Fused with Reciprocal Rank Fusion. 2s per-strategy timeout.

b-side

NAMESPACES

Each agent gets isolated namespaces. Shared where you want, private where you need. Policy at query layer.

solo

SELF-HOSTED LLM

DS-V4-Flash on your hardware. Zero API cost. Zero data leaving your network. Full sovereignty.

diy

FILE STORAGE

Store PDFs, code, web archives. SHA-256 dedup, chunked embeddings. Re-extractable from canonical source.

b-side

PLUGGABLE VECTORS

Start with Neo4j vector index. Swap to Qdrant at scale. Same API, zero code changes. ABC interface.

remix

MCP NATIVE

Agents connect via Model Context Protocol. No system prompt hacking. Just store() and search().

no label
