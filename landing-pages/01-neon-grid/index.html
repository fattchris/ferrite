FERRITE

Persistent Memory for Autonomous AI Agents

A temporal knowledge graph that gives AI agents long-term memory. Agents forget nothing — every conversation, document, and research paper becomes queryable knowledge.

Deploy in 5 Minutes

Features

🔬

Temporal Knowledge Graph

Every fact is timestamped with valid_at and invalid_at. Track how knowledge changes over time. Built on Neo4j for deep graph traversal.

🧠

Observation Consolidation

Raw facts auto-consolidate into evidence-backed beliefs. Proof counts, evidence chains, and staleness tracking adopted from Hindsight research.

🔍

TEMPR Retrieval

Four search strategies in parallel: semantic, BM25, graph traversal, and temporal. Fused with Reciprocal Rank Fusion for best-in-class recall.

🔐

Multi-Agent Namespaces

Each agent gets isolated namespaces. Shared knowledge where you want it, private knowledge where you need it. Policy enforced at the query layer.

⚡

Self-Hosted Extraction

DS-V4-Flash runs on your hardware. Zero API cost. Zero data leaving your network. Full sovereignty over the extraction pipeline.

📂

File Storage

Store actual files — PDFs, code, web archives, voice transcripts. SHA-256 dedup, chunked embeddings, re-extractable from canonical source.

🔌

Pluggable Vector Store

Start with Neo4j's built-in vector index. Swap to Qdrant when you hit scale. Same API, zero code changes. The interface is an ABC.

📡

MCP Native

Agents connect via Model Context Protocol. No system prompt hacking. No fine-tuning. Just a tool call: store() and search().

📉

Tier Freshness Decay

Older facts naturally rank lower in retrieval. Tier 1 (fresh) gets full weight, Tier 3 (>6 months) gets 0.25x. Adopted from Mnemosyne.

How It Works

01

Store

Agents store conversations and documents via MCP. Session transcripts, PDFs, code — all ingested through a single API.

02

Extract

LLM extracts entities, facts, and relationships. Validated against a JSON schema before writing to Neo4j. No hallucinated nodes.

03

Consolidate

Related facts merge into observations — evidence-backed beliefs with proof counts. Staleness tracking flags outdated beliefs.

04

Retrieve

TEMPR fuses 4 search strategies with RRF. Mental models first, then observations, then raw facts. Tier decay weights by freshness.
