FERRITE

Persistent memory for autonomous AI agents — because the mind that forgets is not truly autonomous.

A temporal knowledge graph that gives AI agents long-term memory. Agents forget nothing — every conversation, document, and research paper becomes queryable knowledge. Self-hosted. Zero API cost. Full data sovereignty.

Deploy in 5 Minutes
The Catalog

Nine capabilities that make memory permanent.

No. 01

Temporal Knowledge Graph

Every fact knows when it was born and when it died.

Every fact timestamped with valid_at and invalid_at. Track knowledge changes over time. Neo4j deep graph traversal.

No. 02

Observation Consolidation

Facts become beliefs. Beliefs carry evidence.

Raw facts auto-consolidate into evidence-backed beliefs. Proof counts, evidence chains, staleness tracking from Hindsight.

No. 03

TEMPR Retrieval

Four searches, one answer.

Four parallel strategies: semantic, BM25, graph, temporal. Fused with Reciprocal Rank Fusion. 2s per-strategy timeout.

No. 04

Multi-Agent Namespaces

Shared where you want it. Private where you need it.

Each agent gets isolated namespaces. Policy enforced at query layer. No direct Neo4j access.

No. 05

Self-Hosted Extraction

Zero API cost. Zero data leaving your network.

DS-V4-Flash on your hardware. Full sovereignty. Fallback to Qwen3-8B via Ollama.

No. 06

File Storage & Artifacts

The PDF is the canonical source.

Store PDFs, code, web archives. SHA-256 dedup, chunked embeddings. Re-extractable from canonical source.

No. 07

Pluggable Vector Store

Start with Neo4j. Swap to Qdrant. Same API.

Start with Neo4j's built-in vector index. Swap to Qdrant at scale. VectorStore is an ABC.

No. 08

MCP Native Protocol

No system prompt hacking.

Agents connect via Model Context Protocol. store() and search() — that's it.

No. 09

Tier Freshness Decay

Memory fades. But it never disappears.

Older facts rank lower. Tier 1 (fresh) full weight, Tier 3 (6mo+) gets 0.25x. Adopted from Mnemosyne. Old facts are still findable — just ranked lower.
