FERRITE

PERSISTENT MEMORY
FOR AI AGENTS

A temporal knowledge graph that gives AI agents long-term memory. Agents forget nothing — every conversation, document, and research paper becomes queryable knowledge.

▶ DEPLOY

FEATURES

TEMPORAL GRAPH

Every fact timestamped. Track knowledge changes over time. Neo4j deep graph traversal.

LVL 1

CONSOLIDATION

Raw facts auto-consolidate into evidence-backed beliefs. Proof counts from Hindsight.

LVL 2

TEMPR SEARCH

Four parallel strategies: semantic, BM25, graph, temporal. Fused with RRF. 2s timeout.

LVL 3

NAMESPACES

Each agent gets isolated namespaces. Shared where you want, private where you need.

LVL 4

SELF-HOSTED LLM

DS-V4-Flash on your hardware. Zero API cost. Zero data leaving your network.

LVL 5

FILE STORAGE

Store PDFs, code, web archives. SHA-256 dedup, chunked embeddings.

LVL 6

PLUGGABLE VECTORS

Neo4j vector index → Qdrant at scale. Same API, zero code changes.

LVL 7

MCP NATIVE

Agents connect via Model Context Protocol. Just store() and search().

LVL 8

FRESHNESS DECAY

Older facts rank lower. Tier 1 full, Tier 3 gets 0.25x. From Mnemosyne.

LVL 9
