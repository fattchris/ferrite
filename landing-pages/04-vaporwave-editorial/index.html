FERRITE

Persistent memory for autonomous AI agents — because the mind that forgets is not truly autonomous.

A temporal knowledge graph that gives AI agents long-term memory. Agents forget nothing — every conversation, document, and research paper becomes queryable knowledge. Self-hosted. Zero API cost. Full data sovereignty.

The Catalog

Nine capabilities that make memory permanent.

No. 01

Temporal Knowledge Graph

Every fact knows when it was born and when it died.

Every fact is timestamped with valid_at and invalid_at. Track how knowledge changes over time. Built on Neo4j for deep graph traversal.

No. 02

Observation Consolidation

Facts become beliefs. Beliefs carry evidence.

Raw facts auto-consolidate into evidence-backed beliefs. Proof counts, evidence chains, and staleness tracking adopted from Hindsight research.

No. 03

TEMPR Multi-Strategy Retrieval

Four searches, one answer. RRF decides what matters.

Four parallel search strategies: semantic, BM25, graph traversal, and temporal. Fused with Reciprocal Rank Fusion for best-in-class recall.

No. 04

Multi-Agent Namespaces

Shared knowledge where you want it. Private where you need it.

Each agent gets isolated namespaces. Policy enforced at the query layer. No direct Neo4j access — all reads go through the API.

No. 05

Self-Hosted LLM Extraction

Zero API cost. Zero data leaving your network.

DS-V4-Flash runs on your hardware. Full sovereignty over the extraction pipeline. Fallback to Qwen3-8B via Ollama if unavailable.

No. 06

File Storage & Artifacts

The PDF is the canonical source. The graph is the index.

Store actual files — PDFs, code, web archives, voice transcripts. SHA-256 dedup, chunked embeddings, re-extractable from canonical source.

No. 07

Pluggable Vector Store

Start with Neo4j. Swap to Qdrant. Same API.

Start with Neo4j's built-in vector index. Swap to Qdrant when you hit scale. The VectorStore is an ABC — zero code changes on migration.

No. 08

MCP Native Protocol

No system prompt hacking. No fine-tuning. Just tools.

Agents connect via Model Context Protocol. store() and search() — that's it. Works with Hermes, OpenClaw, Claude Code, and any MCP client.

No. 09

Tier Freshness Decay

Memory fades. But it never disappears.

Older facts naturally rank lower in retrieval. Tier 1 (fresh, <30 days) gets full weight. Tier 2 (30-180 days) gets 0.5x. Tier 3 (6+ months) gets 0.25x and compressed summaries. Old facts are still findable — just ranked lower. Adopted from Mnemosyne's degradation ladder.

The Pipeline

From conversation to knowledge.

1

Store

Agents store conversations and documents via MCP. Session transcripts, PDFs, code — all ingested through a single API.

2

Extract

LLM extracts entities, facts, and relationships. Validated against JSON schema before writing to Neo4j. No hallucinated nodes.

3

Consolidate

Related facts merge into observations — evidence-backed beliefs with proof counts. Staleness tracking flags outdated beliefs.

4

Retrieve

TEMPR fuses 4 search strategies with RRF. Mental models first, then observations, then raw facts. Tier decay weights by freshness.
