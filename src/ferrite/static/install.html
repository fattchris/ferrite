Welcome to Ferrite
Ferrite is a temporal knowledge graph memory system for AI agents. It stores facts with full provenance, tracks temporal changes, and provides multi-strategy retrieval (TEMPR) for context injection.

This installer will guide you through setup in 5 steps.
Prerequisites
  • Docker + Docker Compose v2
  • Python 3.11+
  • uv package manager
  • git
Generate Secrets
